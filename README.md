## 📋 Overview

This repository contains the **Project Proposal** for a final semester Android application project. The project aims to build a WhatsApp clone that works perfectly when internet is available, but automatically switches to a Bluetooth-based mesh network when the internet is down.

**Submitted By:** Azwa Jamal (110846) & Iqra Maqsood Mughal (110847)
**Course:** Android App Development
**Semester:** 6th (BS-IT)
**Submission Date:** 14-04-2026

---

## ✨ Key Features Proposed

* **🌐 Online Mode (Firebase):** One-to-one chat, group chat, media sharing (photos/videos), read receipts, typing indicators.
* **📡 Offline Mode (Bluetooth):** Automatic switching when internet drops. Discover nearby users, send text messages via Bluetooth mesh networking.
* **🔄 Sync Mechanism:** When internet returns, offline messages automatically sync to Firebase.
* **🔒 Security:** AES encryption for messages in both online and offline modes.
